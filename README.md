# ShopFlix

A responsive fashion, beauty, and jewelry storefront with a cinematic dark interface and gold, blue, and green accents. Built with HTML, CSS, and vanilla JavaScript.

## Run locally

From this directory, start a static server:

```bash
python -m http.server 5500
```

Then open `http://localhost:5500`.

## Demo features

- Search and filter the collection
- Preview products, compare styles, and manage a local demo bag and wishlist
- Responsive navigation and newsletter sign-up feedback

Account access, checkout, newsletter delivery, inventory, and social profiles are not connected. Product prices and catalog details are illustrative.
